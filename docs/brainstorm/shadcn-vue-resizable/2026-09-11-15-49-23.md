# shadcn-vue Resizable 接入设计

## 目标

为 Vue 桌面客户端接入 shadcn-vue，并添加官方 `Resizable` 组件。不新增页面，也不修改现有 `App.vue`、路由或布局。

## 方案

使用 shadcn-vue 官方 CLI 初始化项目配置，再添加 `resizable`。CLI 生成项目本地组件源码，后续可按项目需要修改并继续添加其他 shadcn-vue 组件。

不直接使用底层 Reka UI，也不手工复制组件源码。前者不提供 shadcn-vue 的项目结构；后者难以保持与官方生成结果一致。

## 变更范围

- 新增 shadcn-vue 配置文件与主题 CSS 变量。
- 安装 Resizable 所需依赖。
- 在 `apps/client/src/components/ui/resizable/` 生成组件入口及其组成部分。
- 沿用 Vite 中已有的 `@` 路径别名。

## 非目标

- 不展示或实例化 Resizable。
- 不改变现有页面、路由、布局或应用行为。
- 不调整与组件接入无关的依赖和样式。

## 验证

运行客户端类型检查或构建，确认生成的组件、路径别名和依赖能被项目解析。
